## 팔레트 (토큰 이름으로만 지칭할 것)

| 토큰 | 용도 |
|---|---|
| `color.bg-deep` | 배경(암부) |
| `color.tile-a` / `color.tile-b` | 바닥 타일 체커 |
| `color.line` | 구조 라인, 비발광 외곽선 |
| `color.hologram` | UI·홀로그램·발광 외곽선 액센트 |
| `color.danger` | 위험/경고 (UV 경보, 오답 프레임) |
| `color.success` | 성공/가시광 연출 |
| `color.spectrum-*` | 1막 선 스펙트럼 원색 (red/cyan/blue/violet) |
| `color.text` | 본문 텍스트, 오브젝트 상호작용 라벨 |
| `color.screen-bright` | 콘솔 스크린(방에서 가장 밝은 면) — 컨셉 실측 |
| `color.console-body` | 기기 몸체 회색 — 컨셉 실측 |
| `color.char-*` | 캐릭터 전용 난색 세트(coat/coat-shadow/hair/hair-shadow/skin/dark) — 컨셉 실측. **난색은 캐릭터 전용**, 환경·UI에 사용 금지 (danger 연출만 예외) |

- SVG 원본에는 hex를 직접 쓰지 않는다. `{{color.hologram}}` 플레이스홀더로 쓰면
  빌드(`npm run assets`)가 치환한다. **hex 하드코딩은 훅이 차단한다.**

## 뷰 · 치수

- 2.5D 아이소메트릭, 타일 2:1 비율 (`tile.w`=128 × `tile.h`=64 px)
- 바닥은 **윤곽선 없는 두 톤 체커**(tile-a/tile-b 교대) — 타일에 스트로크 금지
- 캐릭터: **사용자 제작 원본(assets-src/char_asset/, 1024px 3뷰 시트 2장 — 남/여)** →
  `node scripts/import-char.mjs`가 배경(흰색·체커보드) 플러드필 제거·갇힌 포켓/얼룩 정리·
  디프린지·3뷰 자동 분할·48px 다운스케일·걷기 프레임
  생성(다리 픽셀 수술)·그림자 합성·미러를 거쳐 assets-src/ext-char/ 36프레임
  (남/여 × se/sw/ne/nw/e/w × idle/a/b, ×5 스케일 = 화면 240px)으로 산출.
  원본 교체 시 스크립트만 재실행.
  ext-char가 .pix 폴백(assets-src/char/)보다 우선. 검수는 `scripts/char-sheet.mjs`
- 오브젝트 원점: 타일 마름모의 바닥 중심점 기준으로 정렬
- 밝음의 위계: screen-bright > hologram > text > 환경. 글로우는 스크린·UI에만

### 크기 기준 — 월드 배율과 카메라 줌을 분리한다

두 층으로 나뉜다. **월드 배율**은 사물끼리의 비율, **카메라 줌**은 한 화면에 얼마나
담을지를 정한다. "너무 크다/작다"는 대부분 줌 문제이므로 개별 에셋 배율을 건드리지 말 것 —
그러면 애써 맞춘 비율이 다시 깨진다.

**① 월드 배율 (비율)** — 프리렌더 배경의 가구가 척도. 서 있는 사람 = 월드 240px 기준
(1m ≒ 140px).

| 대상 | 월드 높이 | 맞추는 법 |
|---|---|---|
| 캐릭터 | 240px | `assets-src/ext-char/meta.json`의 `scale` (현재 5 = 48px 원본 ×5) |
| 오브젝트(콘솔·문·가구) | 사물함≈250 / 책상≈220 / 콘솔≈220 | `assets-src/asset-scale.json`에 `{이름: 배율}` — 없으면 1 |
| 뒷벽(배경 없는 방) | 가구보다 높게 | `Game.ts`의 `WALL_STRETCH` (현재 2) |

**② 카메라 줌 (시야)** — `Game.ts`의 `CAMERA_ZOOM` (현재 0.5). 배경·타일·벽·캐릭터·사물에
균일 적용되므로 비율은 그대로고 보이는 범위만 바뀐다. 화면 실제 크기 = 월드 높이 × 줌
(캐릭터 240 × 0.5 = 120px).

- 줌에 딸려 줄면 안 되는 것은 코드에서 `/ CAMERA_ZOOM` 보정한다 —
  수색 스파클, 암막 광원 반경, 상호작용 라벨(DOM), 그리고 `asset-scale.json`의 `note`(×2).
- 배율은 nearest 확대라 **정수 배율**을 쓴다 (1.5 같은 값은 픽셀이 뭉갠다).
- 새 방 배경이 오면 ①만 그 방 가구에 맞춰 재검증한다. 캐릭터 배율은 전 방 공통이므로
  배경 쪽 `background.scale`로 맞추는 편이 안전하다.

## 형태 언어

- 단순 기하 + 가는 발광 외곽선 (`stroke.outline`=2px, glow blur `stroke.glow-blur`=6)
- 텍스처 없음. 플랫 면 + 글로우만으로 재질감 표현
- 모서리 라운드는 `corner-radius`=4 통일

## 타이포그래피

- Pretendard 또는 Noto Sans KR (무료). 홀로그램 텍스트는 자간 넓게 (`font.holo-letter-spacing`)

## AI 생성 에셋 (scripts/gen-asset.mjs) — 데코·소품의 기본 제작 경로

- 무료 생성 API(Pollinations, 키·비용 없음)를 스크립트로 감싸 사용한다.
  `node scripts/gen-asset.mjs <name> "<영어 설명>"` 또는 `--batch scripts/asset-batch.json`
- 스타일 템플릿 2종이 스크립트에 고정돼 있다 (batch의 `"style"` 필드로 선택):
  - **decor**(기본): 현실적인 일반 실험실 풍 — 자연색(흰·회색·나무·스틸), 네온 금지.
    어두운 방 + 밝고 또렷한 가구 = 가독성 (캐릭터 베이지 코트와 같은 원리)
  - **device**(퍼즐 장치 전용): 어두운 금속 + 은은한 시안 발광 — "만질 수 있는 것"의 신호
  - 공통: 받침대·좌대·바닥 조각 금지 문구 포함 (자기 바닥을 달고 나오면 디오라마처럼 뜬다)
  설명에는 **오브젝트 자체만** 쓴다 — 스타일 단어를 중복 기술하지 말 것.
- 후처리: **가장자리 플러드필 배경 제거**(전역 키잉 금지 — 내부에 구멍 남) + 전역 마젠타
  제거 + 디프린지 → 크롭 → 픽셀 다운스케일. **팔레트 스냅은 기본 해제**(`--snap` 옵트인) —
  게임 팔레트가 암색 위주라 하드 스냅 시 중간톤이 탁해진다. 톤 통일은 프롬프트가 담당.
- 원본은 `assets-src/gen-src/`(캐시), 최종본은 `assets-src/gen/*.png` → 빌드가 패스스루.
  같은 이름 재생성은 `REGEN=1` + seed 변경.
- **품질 게이트**: 생성물은 반드시 Read로 직접 보고 판정한다. 형태가 뭉개졌거나
  오브젝트가 여러 개면 seed를 바꿔 재생성. 통과본만 커밋.

## 데코 배치 원칙 (GameMap.decor)

- 목적: **꽉 찬 차가운 실험실** — 어수선함 속에서 조작 대상을 찾는 것이 방탈출 경험.
  방마다 데코 16~24개: 뒷벽(y=0 행·x=0 열)을 따라 가구 라인업 + 내부 클러스터 +
  바닥 케이블 2~3줄 + `wallDecor`(칠판·포스터·야경 창) 2~4개 + `light: true` 형광등 2개
- `flat: true`(얼룩·파편·서류·케이블)는 바닥에 깔리고, 입체물은 깊이 정렬에 참여.
  `light: true`(lamp-tube)는 공중에 떠서 바닥에 한랭 광 풀을 드리운다
- 벽걸이(`GameMap.wallDecor`)는 정면 평면 아트(wall 템플릿)로 생성 — 엔진이 벽
  기울기(±1/2)에 맞춰 셰어 부착하므로 원근을 그리지 말 것
- 퍼즐 오브젝트·문·노트에서 1타일 이상 띄운다 (상호작용 라벨 겹침 방지)
- **수위 가이드 (주요 사용자 = 학생)**: 유혈·신체 묘사 금지. "핏자국"은
  갈색의 오래된 얼룩(stain-old)으로 암시만. 깨진 유리·마른 화분·흩어진 서류처럼
  "시간이 멈춘 흔적" 위주로. 공포보다 쓸쓸함.

## 제작 규칙 (5중 강제 장치 요약)

1. **레퍼런스**: `docs/reference/concept.png`를 매번 직접 본다 (등록 후)
2. **토큰 단일 소스**: 색·치수는 design-tokens.json만. SVG는 `{{ }}` 플레이스홀더
3. **프리미티브 조합**: `assets-src/_lib/`의 공통 부품(`iso-tile-base`, `glow-outline`,
   `holo-frame`, `panel`)을 조합해 만든다. 처음부터 그리지 않는다
4. **나란히 비교**: `tools/asset-viewer.html` 3분할(컨셉/신규/승인 에셋)로 검증,
   통과본은 `docs/reference/golden/`에 누적
5. **훅 차단**: assets-src/ 아래 SVG에 토큰 외 hex가 있으면 쓰기 자체가 차단됨

신규 부품·신규 색이 필요하면 먼저 사용자 승인을 받아 토큰/라이브러리에 등록한 뒤 사용한다.
