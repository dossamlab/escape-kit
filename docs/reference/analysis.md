## 전체 무드

- 어두운 청회색 공간에 아이소메트릭 체커 바닥이 마름모 "섬"으로 떠 있음.
  바닥 밖은 약간 더 어두운 배경 → 방의 경계가 자연스럽게 어둠에 잠긴다.
- 광원 연출 없음(플랫). 유일한 밝은 요소는 콘솔의 청사진 스크린 — 시선 유도 장치.

## 요소별

| 요소 | 관찰 | 실측 색 (토큰) |
|---|---|---|
| 배경 | 바닥 밖 여백. 타일보다 반 단계 어두움 | `#212531` (color.bg-deep) |
| 바닥 체커 | 2:1 마름모, 윤곽선 없이 명암 두 톤 교대. 이음새 없음 | 밝은 칸 `#2b303b` (tile-a) / 어두운 칸 `#252935` (tile-b) |
| 콘솔 | 중간 회색 받침대 + 앞으로 기울어진 스크린. 스크린은 밝은 청백색 바탕에 청색 도식(청사진 느낌). 기기 자체 발광은 은은함 | 몸체 `#42454d` (console-body), 스크린 `#e1e9f6` (screen-bright), 도식 라인은 hologram 계열 |
| 캐릭터 | 픽셀아트, 신장 약 2/3타일 폭. 짙은 외곽선. **차가운 배경 속 유일한 난색 덩어리** — 존재감의 원천 | 코트 `#c2ae8b` (char-coat), 코트 음영 `#907c62` (char-coat-shadow), 머리 `#76212b` (char-hair) + 음영 `#441021` (char-hair-shadow), 피부 `#ecbd9b` (char-skin), 바지·부츠·외곽선 `#17171a` (char-dark) |
| 상호작용 라벨 | 오브젝트 위 흰색 고딕 텍스트 "이름 (키 안내)". 프레임 없음 | color.text |

## 규칙으로 승격할 것

1. **바닥은 윤곽선 없는 두 톤 체커** — 타일에 스트로크를 넣지 않는다.
2. **난색은 캐릭터 전용** — 환경·UI는 한색(청회색+hologram), 캐릭터만 난색(coat/skin/hair).
   위험 연출(danger)만 예외.
3. **밝음의 위계**: screen-bright(콘솔 스크린) > hologram(UI 라인) > text > 환경.
   콘솔 스크린이 방에서 가장 밝은 면이어야 한다.
4. 오브젝트는 짙은 외곽선(char-dark 계열)으로 배경과 분리, 글로우는 스크린·UI에만.
5. 캐릭터 비례: 머리 큼(전체의 ~1/3), 몸통 슬림, 발밑 타원 그림자.
