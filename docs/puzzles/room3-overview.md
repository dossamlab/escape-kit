# 「이름 없는 방」(탄성파와 소리) — 방 설계서

> **방 하나를 기획할 때 쓰는 문서의 본보기다.** `/new-subject`가 네 교과 버전을
> `docs/puzzles/room1-overview.md`로 만든다 — 절 구성(구조·퍼즐 목록·코드 배정·성취기준)을 따를 것.

방 = `sonic-room` — 관측동 최심부 **청음실**, 「이름 없는 방」(2번 방 계통도의
"빈칸에 물음표" 떡밥 회수). 크기 24×24 목표(최종 N은 배경 에셋 캘리브레이션 역산 —
1번 방 전례: 24 요청 → 20 착지). 2막의 **마지막 방** — 엔딩으로 이어진다.

**방 방향(사용자 확정)**: 1·2번 방보다 게임적 흥미·실제 방탈출 느낌 강조. 교육과정
개념은 가볍게(전 퍼즐 계산 0~1줄), 깊이는 원리 카드 담당. 오디오 적극 사용 +
**모든 판정은 시각 정보만으로도 가능**(무음 환경 백업). 퍼즐 4개 + 연출·수색 강화.
**아이템 게이트 첫 사용 승인**(P2 릴 테이프 → 최종 콘솔).

## 방 구조 (1·2번 방과 다르게 — 3단 연출)

```
진입부 [암전 dark.litByEvent] ─ P1 진자 발전기 → power-restored → 조명 복구
본실  ─ P2 벽 노크 그리드 / P3 무음점(모달 없음, 방 전체) / 수색 5곳 / 노트 6개
봉인 녹음 부스+앞마당 [sealed booth·booth-annex, opensWhen: P2 AND P3]
  ─ P4 모노코드(**앞마당** [14.9,9] — 부스 안에 두면 스프라이트가 유리벽 관통,
  유리문 아트와도 겹쳐 2026-08-04 이전) + 최종 콘솔(부스 안) → 출구(ending)
  ※ **최종 콘솔은 스프라이트가 없다** — 배경 그림의 부스 안 책상·모니터가 곧 콘솔이고
  tile [15,1]이 그 위를 가리킨다(서쪽 출구 문과 같은 처리). 유리 앞에 그릴 것이
  없으니 가릴 것도 없다: 배경 재드로우 판(background.overpaint)은 2026-08-04 삭제.
  부스 바닥 실측 x∈[13.6,18.6]·y∈[-1.4,3.55] — 옛 콘솔 [17.8,2.4]는 그림 속 의자,
  옛 note-44 [18.9,1.1]은 부스 동쪽 유리 바깥이었다.
  ※ 두 봉인이 맞닿은 안쪽 변(y=6)에는 격벽을 세우지 않는다(엔진: 변 바깥 isSealed
  프로브). 봉인 렌더는 어둠 전체→격벽 전체 2패스 — 한 패스면 뒤 구역 어둠이 앞 구역
  격벽을 덮어 이음매에 톤 차이가 생긴다.
```

- **암전 오프닝**: 입장 시 방이 어둡고 비상등만 깜빡인다. 어둠 속 진자 소리('똑…')의
  스테레오 패닝이 P1 위치를 안내하고, 비상등 깜빡임이 진자 박자와 동기(시각 백업).
- **봉인 부스**: `opensWhen: ["code:knock-solved", "code:node-solved"]` — 둘 다 봉인 밖.
- **아이템 게이트(이 방의 규약 변경, 사용자 승인)**: P2가 벽 속에서 **릴 테이프**를
  내주고, 최종 콘솔은 테이프 없이 돌지 않는다. 엔진 `gate.items` 첫 활용.

## 코드 구조 (1번 방 4자리, 2번 방 3자리+값과 다르게)

숫자가 아니라 **4음 멜로디**. 퍼즐 4개가 각각 음 하나(음이름+색+순번)를 내고,
최종 콘솔은 **8건반 미니 건반**에 4음을 순서대로 연주해야 연다. 구현은 기존 키패드
코드 게이트의 스킨(8건반 = 숫자 1~8 매핑) — 엔진 수정 최소. 건반은 색+음이름+파형
높이를 함께 표시(무음 백업). 코드 조각은 원리 카드 마지막 줄에 병기(저널 재열람).

그 4음 멜로디는 **한이준이 늘 불던 휘파람 4음** — 엔딩 도플러 판독에서 회수된다.

| 퍼즐 | 성취기준 | 조작 | 판정 핵심 | 보상 |
|---|---|---|---|---|
| P1 pendulum-dynamo | 03-01 | **리듬 탭**(진자 박자에 맞춰 밀기) | 위상 코사인 | `power-restored`(조명) + 음1 |
| P2 wall-sounding | 03-02 | **그리드 청진 탭**(에코 판별) | 이중 피크 패널 | **릴 테이프** + 음2 |
| P3 silent-node | 03-04 | **아바타 이동**(모달 없음) | 경로차 무음 타일 | 경보 정지 + 음3 |
| P4 monochord | 03-05 | **현 위 지점 탭**(하모닉스) | f = n·f₀, L/3·2L/3 | 음4 |
| 최종 콘솔 | 03-03 | 테이프 장착 → 4음 연주 → 도플러 이지선다 | — | `door:sonic-open` |

**설계 문법(2026-08-02 개편 승계)**: 전부 개념 없이 방향성 있는 피드백으로 수렴.
단서는 지름길이지 게이트가 아니다. 원리는 해결 후 원리 카드가 담당.

조작 15종 중복 없음: 1막(슬롯 드래그·±스테퍼·속도감지 드래그·회전 버튼·타겟 드래그) /
1번 방(원형 다이얼·2D 벡터·1D 핸들·탭 토글·카드 재정렬) / 2번 방(2축 슬라이더·시공+
스윕·홀드 가열·무명 카드 배치·영상 판정) 어디에도 해당 없음. P2는 상태가 남지 않는
즉발 관찰이라 탭 토글과 구별, P4는 드래그·핸들 없는 불연속 탭이라 1D 핸들과 구별.

## P1 `pendulum-dynamo` — 진자 발전기 [12역학03-01] · 중하 (오프너)

**물리**: 단진동의 등시성 — 진자의 주기는 진폭과 무관. 판정 물리는 03-01 범위
(단진동) 안이고 '공명'은 연출 언어로만(그네 밀기 직관).

- 어두운 방, 비상 발전기의 큰 진자가 약하게 흔들린다. [밀기] 버튼(모바일: 탭)을
  **진자의 박자에 맞춰** 누르면 진폭이 자라고, 어긋나면 오히려 준다.
- 수렴: 마구 눌러도 게이지 증감이 즉시 보임 → "박자에 맞을 때만 커진다"를 2~3회에
  발견. 밀기 좋은 순간 버튼이 살짝 발광(리듬게임 문법, 시각 백업).
- 판정: `Δ진폭 ∝ cos(φ_밀기 − φ_최적)` 한 줄. 진폭 ≥ 임계 1초 유지 → 해결.
- 오디오/시각: 진자 통과음 '똑' + 모터 헛도는 소리 → 시동음 / 진자 애니메이션 +
  진폭 게이지 + 버튼 발광.
- 오개념 방지: 밀기 '세기' 개념 자체를 제거(탭은 온/오프). 카드가 등시성 명시.
- 지름길: "진자는 크게 흔들리든 작게 흔들리든 같은 박자로 돌아온다."
- 힌트: ① "발전기는 힘이 아니라 박자를 원한다" ② "진자가 가장 낮은 곳을 지날 때를
  봐라" ③ "'똑' 소리에 맞춰 눌러라."
- 보상: `power-restored`(암전 해제) + **음1**.

## P2 `wall-sounding` — 벽 노크 탐상 [12역학03-02] · 중하~중 (수색형)

**물리**: 탄성파는 매질 경계에서 반사된다 — 두드린 파가 벽 속 빈 공간 경계에서
되돌아와 **두 번 울린다**. 초음파 탐상·지진 탐사와 같은 원리(성취기준 '활용 예' 직결).

- 벽면 패널 그리드(4×6). 패널 탭 → '쿵' + 옆의 낡은 오실로스코프에 에코 파형.
  대부분 단일 감쇠 펄스(꽉 찬 벽), 한 장만 **피크 둘**(속이 빔). 찾아 열면 벽감에
  **릴 테이프**. 실제 방탈출의 "벽 두드려 비밀 공간 찾기"를 물리로 옮긴 것.
- 수렴: 전수 노크 24회로도 반드시 풀림 — 소리/파형 차이가 명백. 수색 단서(지름길):
  "빈 곳은 두 번 운다."
- 오디오/시각: 꽉 찬 벽 '턱'(둔탁) vs 빈 벽 '통—통'(울림) / 파형 반사 피크 2개 —
  파형만으로 완전 판별.
- 오개념 방지: 파형에 반사 피크를 명시해 '되돌아온 것'임을 보여줌("흡수"로 오해 방지).
- 힌트: ① "이 방의 벽은 전부 같은 소리를 내지 않는다" ② "파형의 봉우리 개수를 세라"
  ③ "두 번 울리는 패널 뒤가 비어 있다 — 열어라."
- 보상: **릴 테이프**(아이템) + **음2**. 구현: 패널별 부울 + 캔버스 펄스(물리 시뮬 불필요).

## P3 `silent-node` — 무음 지점 [12역학03-04] · 중 (방 전체 기믹, 모달 없음)

**물리**: 두 스피커가 같은 진동수의 음을 내면 간섭 무늬가 생긴다 — 경로차가 반파장의
홀수배인 지점은 상쇄되어 조용하다. 노이즈 캔슬링의 원리.

- 조명 복구와 함께 스피커 2대가 거슬리는 정현음(봉인 부스 잠금 경보)을 낸다.
  **모달이 없다 — 방 자체가 퍼즐.** 걸어다니면 위치에 따라 음량이 변하고, 소리가
  완전히 죽는 타일에서 ACT → 바닥 해치의 경보 차단 스위치 → 스피커 정지.
- 수렴: 걷기만 해도 음량이 연속 변화(뜨겁다/차갑다 수렴). 개념이 있으면 "두 스피커
  한가운데 축은 오히려 크고, 죽는 곳은 그 옆줄" 직행.
- 판정: `진폭 ∝ |cos(π·(d₁−d₂)/λ)|` 한 줄 + 타일 판정. λ=6타일 → 마디선은
  중앙축 좌우 쌍곡선 두 가닥(물리적으로 양쪽 다 조용함 — 정직). **해치는 동쪽
  가닥에만** 있고, 스프라이트·라벨이 최종 확정 신호. 등진폭 근사는 autoplay에 명시.
- 오디오/시각: 위치 연동 실시간 음량+패닝 / **HUD 소음 미터 상시 표시** + 무음점
  부근 바닥 간섭 무늬 발광 — 미터만으로 풀림.
- **해치 모달 = 반위상 주입 미니 과제 (2026-08-04 개편)**: 원버튼 페이오프가
  "퍼즐감이 없다"는 실플레이 피드백으로 개편. 캔버스 3행(경보 신호 / 주입 신호 /
  합성) — 주입 신호를 **가로 드래그**(api.onDrag)해 위상을 밀고, 합성 진폭
  `|cos(Δφ/2)|`이 `PHASE_SUM_TOLERANCE`(유일 노브, 0.15) 이하로 평평해져야
  차단 스위치가 활성화된다. 시작은 동위상(합성 **2배** — 마루+마루)이라 중첩
  원리의 양끝을 손으로 오간다. e2e 드래그량은 렌더폭/WAVE_CYCLES/2로 환산.
- 오개념 방지: 흡음이 아니라 상쇄 — 정렬 성공 캡션과 원리 카드가 담당.
  '에너지가 사라진 게 아님'은 원리 카드 담당.
- 힌트: ① "이 소음은 끌 수 없다 — 피할 수 있을 뿐" ② "방을 천천히 걸어라. 미터가
  길을 안다" ③ "두 스피커의 한가운데가 아니라 거기서 한 발 비껴난 줄이 조용하다."
  ④ 해치 패널 조작 안내(주입 신호를 끌어 반대 위상으로).
- 보상: 경보 정지 + **음3**. 엔진 소요: 위치 연동 룸 오디오 + HUD 미터 + 타일 판정
  훅(모달 없는 첫 퍼즐).

## P4 `monochord` — 모노코드 하모닉스 자물쇠 [12역학03-05] · 중상 (부스 안)

**물리**: 양 끝 고정 현의 정상파. 한 점을 가볍게 짚으면 그 점을 **마디**로 갖는
배음만 살아남는다 — L/2 = 2배음(옥타브), L/3 = 3배음. 현악기 하모닉스 주법.

- 부스 자물쇠: "이 현이 낼 수 없는 음을 내라." 개방현은 낮은 '도', 목표는 높은
  '솔'(3배음). 현 위 지점을 **탭하면 짚은 채 자동으로 튕겨진다**. 마디가 될 수 있는
  지점(1/2, 1/3, 2/3, 1/4…)만 맑게 울리고, 아무 데나 짚으면 '툭' — 실제 기타와 동일.
- 수렴: 여기저기 짚어 보면 "울리는 지점이 몇 군데뿐"임을 몸으로 발견. 울릴 때마다
  음이름이 표시되어 목표 음과 대조하며 수렴.
- 판정: `f = n·f₀` + 위치 허용 오차. **L/3과 2L/3 복수 정답 인정**(물리적으로 옳음).
- 오디오/시각: Web Audio 배음 재생 / 현 위 정상파 형상(배·마디) 실시간 표시 +
  마디 적중 시 파형 선명·음이름 점등, 어긋나면 흐릿+무음 아이콘.
- 오개념 방지: '가볍게 짚기(하모닉스)' vs '꽉 눌러 길이 줄이기(프렛)'를 도입 대사와
  카드에서 명시 구별. 이 퍼즐의 짚기는 항상 하모닉스.
- 힌트: ① "자물쇠는 이 현의 '낼 수 없는 음'을 원한다 — 정말 낼 수 없을까" ② "현을
  가볍게 짚고 튕겨라. 울리는 자리는 몇 곳뿐이다" ③ "현을 세 등분하는 자리를 짚어라 —
  어느 쪽 3분점이든."
- 보상: **음4**.

## 최종 콘솔 — 퍼즐 아님, 연출 게이트 [12역학03-03 회수]

1. **아이템 게이트**: 릴 테이프(P2) 장착.
2. **멜로디 게이트**: 8건반에 4음 순서 연주(기존 키패드 코드 게이트 스킨).
3. **도플러 판독(1문항)**: 마지막 지오폰 기록 — 휘파람 4음이 점점 **낮아지며**
   잦아든다. 화면엔 스펙트로그램 피치 트레이스(내려가는 선, 무음 백업).
   "이 소리가 다가오는 것인지, 멀어지는 것인지. 그것만 답해라." [다가옴/멀어짐].
   정답 '멀어짐' = "그는 살아서 걸어 나갔다" — 서사적 답과 동시에 문이 열린다.
   오답 시 부드러운 재시도(사이렌 접근/후퇴 비교 재생).

## 서사 (열린 엔딩 + 3막 훅, 사용자 확정)

- 그가 마지막에 재던 것 = 지오폰으로 듣던 **지반 침하**. 시계가 어긋난 이유(1번 방
  에필로그 떡밥) = 침하로 시계들의 높이(중력 퍼텐셜)가 달라짐 — 1번 방 개념 회수.
- 릴 테이프 = 2막 내내 차갑던 '라플라스 녹음'이 아닌, 처음 나오는 **한이준의 육성**.
  "방향은 정해져 있어도, 언제 어떻게 갈지는 선택이다." 관측동을 봉인하고 떠났다.
- 도플러 판독 = "멀어짐" → 1번 방 수색 떡밥 "귀환한 사람은 없다"의 회수 — 그는
  귀환하지 않았다. **앞으로 갔다.**
- 에필로그: 빈 문패 — "이 방의 이름은 네가 붙여라." 노트 완독 시 새 관측지 좌표 +
  "커피는 그곳에서. 이자는 쳐서 갚지."(3막 훅) / 미완독 시 "기록은 도망가지 않는다."
