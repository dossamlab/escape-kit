## 탄성파와 소리: 퍼즐 ↔ 성취기준

⚠ **출처 캐비앗.** 전문 출처는 나무위키 「2022 개정 교육과정/과학과/고등학교/역학과 에너지」 —
서로 다른 판(r14·r17·r31·r67)에서 5개 코드 전문이 동일함을 교차 확인(2026-08-03).
조선대 리포지토리 성취기준 분석 PDF·경기도교육청 최소 성취수준 자료가 해당 코드를 포함한다는
검색 수준 방증은 있으나 전문 대조는 실패(fetch 불가). **NCIC 고시 원문 대조가 남아 있다.**
퍼즐 매핑은 대조 결과와 무관하게 유지되는 수준으로 잡았다.

**이렇게 솔직히 적는 것이 이 문서의 용법이다** — 검증 부채를 숨기지 말고 표에 남긴다.

설계 방침: 이 방은 **개념 부담을 낮추고**(전 퍼즐 계산 0~1줄) 깊은 개념은 해결 후
원리 카드가 담당한다. 조작 방식은 서로 겹치지 않는다 — 리듬 탭 / 그리드 청진 탭 /
아바타 이동 음장 탐색 / 현 위 지점 탭 / 건반 연주 게이트.

## 예외 표

성취기준과 퍼즐이 100% 일치하지 않아도 된다. 다만 **불일치는 반드시 여기 적고 승인받는다** —
이 표가 없으면 매핑이 슬그머니 어긋난다. 신규 예외는 사유 명시 + 사용자 승인 후 등재해야
사용할 수 있다.

| 퍼즐 | 예외 내용 | 승인 근거 |
|---|---|---|
| pendulum-dynamo | [12역학03-01]의 예시 기구는 '용수철 진자'인데 퍼즐은 실 진자를 쓴다 (내용요소 단진동·등시성·a∝−x는 동일하게 커버, 실 진자는 소각 근사에서 단진동) | 발전기 기믹(그네 밀기 직관)에 실 진자가 자연스럽고, 성취기준의 핵심은 기구가 아니라 단진동 개념 — physics-reviewer 검수(2026-08-03)에서 매핑 유지 판정 |
